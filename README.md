# Primeira Manhã — AI daily prayer app

> **Showcase repository.** The source code is private; this page documents the product.
> Co-built at RuneLabs by [Roderick Specter](https://github.com/rodcoding123) and Mateus Maia.

Primeira Manhã ("First Morning") is a mobile app for Brazilian Christians that helps people start the day with prayer: selected distracting apps stay **locked until the user completes a daily prayer generated by AI** for their moment of life.

## Product
- AI-generated daily prayers personalized to the user's context and mood
- **App locking**: the user chooses which apps stay blocked until the prayer is done
- Insights on the user's prayer journey
- Subscriptions and attribution for growth
- Pitched to a major Brazilian church leader as a brand-licensing plus technology-as-a-service partnership, with a custom HTML pitch deck and design system

## Architecture: local-first, privacy by design
- **All user data stays on the device** (AsyncStorage + SQLite): no backend database
- Works offline except for AI generation
- Claude API for prayer generation

## Tech stack
`React Native (Expo)` `TypeScript` `SQLite` `Anthropic Claude` `RevenueCat` `Branch.io`
